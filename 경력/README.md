## 온품 (현재)

| 사이트 | https://onpoom.co.kr/ |

물리적 공간을 디지털로 복제한 디지털 트윈 기반 모니터링·분석·시뮬레이션 전문 기업.

React 기반 사내 및 공공 플랫폼에서 3D 기반 지도 플랫폼 개발을 담당. 대용량 공간 데이터와 좌표 정보를 효율적으로 시각화하기 위해 렌더링 구조를 설계하고, 확장 가능한 지도 아키텍처를 구축. 다양한 관제·분석 기능과 연계될 수 있도록 구조적 유연성을 고려해 구현.

### 주요 업무 및 성과

- **MFA(Micro Frontend Architecture) 기반 3D 지도 플랫폼 설계 및 구현**
  - 3D 공간 데이터 시각화, 레이어 관리 구조 설계
  - 대용량 좌표 데이터 처리 및 렌더링 성능 최적화
  - 다른 개발사 코드와 독립적으로 배포 가능한 구조 설계
- **지도 인터랙션 및 UX 개선**
  - 줌·이동·객체 선택 등 사용자 인터랙션 최적화
  - 데이터 가독성을 고려한 시각적 표현 및 UI 구성
- **확장 가능한 지도 아키텍처 구축**
  - 기능 모듈화로 관제·분석 시스템과 연계 가능하도록 설계
  - 신규 기능 추가 시 영향 범위를 최소화하는 구조 확립
- **GPU 인프라 표준화 아키텍처 구축**
  - 여러 팀·사용자가 물리 GPU(A100) 한 대를 MIG로 동시에 안전하게 나눠 쓰도록 설계
  - 배포 전 모델이 해당 MIG 슬롯에서 정상 동작하는지 사전 검증하는 구조 마련
- **리눅스 서버 침해 사고 발견 및 대응**
  - 비정상적 서버 부하·접근 이력을 직접 발견하여 침해 사고 인지
  - SSH 무차별 대입 공격 경로 확인, 의심 계정의 sudo/docker/lxd 권한 악용 사실 파악
  - 악성 계정 잠금, SSH authorized_keys 백도어 제거(immutable 속성 해제 포함), crontab 악성 항목 삭제, 악성 프로세스 종료 조치
  - /usr world-writable 권한 복구, 서버 포맷 및 검토된 데이터 선별 이전 권고
  - 관련 기록: https://ravenkim97.tistory.com/612

빅데이터 분석 기반 AI 모델 및 응용 서비스를 개발하는 AI 전문기업.  
프로젝트 목록: https://ravenkim97.tistory.com/554

React 기반 사내 및 공공 플랫폼에서 데이터 시각화 솔루션 구축, 재사용 가능한 공통 컴포넌트 개발, 확장성 있는 프런트엔드 아키텍처 설계를 담당. 다양한 LLM 서비스를 위한 일관된 디자인 시스템을 구축하였으며, 대규모 데이터 처리 성능 최적화를 통해 시스템 효율성을 향상.

### 주요 업무 및 성과

- **보일러플레이트 제작** → 평균 배포시간 5분 → 30초로 단축, 유지보수성 확보, 일관된 UI/UX 체계 확립
- **Micro Frontend 아키텍처 설계** → Module Federation 기반 Host·Remote·Shell 역할 분리, 공유 패키지 레이어(@repo/packages/fe-ui, fe-utils) 구성, 독립 배포 실현. 설치부터 인증 설계까지 14개 섹션 문서 체계 완비
- **LLM 시각화 템플릿 구축** → 새로운 LLM 프로젝트 도입시간 1달 → 2주 단축
- **고성능 공통 컴포넌트 개발** → 30만 건 데이터까지 처리 가능한 테이블, 그래프, 파일 처리기 개발
- **다양한 도메인 경험** → MLOps 데이터 관리, CCTV 관제, AI 챗봇, 다차원 네트워크 시각화, 연구지원시스템, 인사관리 시스템

### 기술 스택

- Main: React
- Sub: Django, Spring, Docker, SQL
