## 한 줄 소개

> 구조적인 설계를 바탕으로 보안까지 고려하는 개발자, 김해준입니다.  
> React 기반의 보안을 중시하는 4년차 웹 프론트엔드 개발자.

다양한 데이터 시각화 프로젝트와 솔루션을 경험하며 기획부터 개발, 유지보수까지 폭넓게 참여해 왔습니다. 팀의 기반을 다지는 데 집중하며 구조적이고 확장 가능한 코드 작성에 힘써왔고, 이를 통해 사용자 경험과 개발 생산성을 함께 고려한 반복 업무의 자동화와 공통화에 관심을 가지게 되었습니다. 정보보안 전공을 살려 웹 크래킹에 안전한 웹 환경을 지향합니다.
